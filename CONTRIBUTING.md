# Contributing

All contributions are welcome. Bug reports, bug fixes, documentation improvements, enhancements, and ideas are all valuable.

## How to Contribute

1. Fork the repository and create a branch for your change.
2. Make a focused update that keeps the project simple.
3. Test the Bash script with representative inputs.
4. Update the documentation when the behavior or usage changes.
5. Open a pull request describing what you changed and why.

Please use clear commit messages and be respectful in issues and pull requests.

## Reporting Bugs

Bug reports are welcome. Include the command or input that caused the problem, the expected result, and the actual result.
